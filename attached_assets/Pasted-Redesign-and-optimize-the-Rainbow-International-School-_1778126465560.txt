Improve the current home page without changing the core Rainbow International School brand identity. The page should look premium, modern, parent-friendly, fast-loading, and conversion-focused. Rainbow International School is a CBSE-affiliated Nursery to Class 12 school in Thane, established in 2009, with a 3.5-acre campus, strong academics, sports, safety, co-curricular exposure, transport support, parent communication systems, and a holistic school environment.

16. UI design guidelines

Follow these UI guidelines across the page:

- Maintain premium blue, white and gold colour palette.
- Use consistent button styles.
- Use one primary CTA colour for “Book a Campus Visit”.
- Avoid too much empty white space between sections.
- Keep section heights balanced.
- Use rounded cards with soft shadows.
- Use real school images wherever possible.
- Avoid generic stock visuals.
- Keep typography clean and readable.
- Use large headings but avoid oversized text on mobile.
- Maintain strong contrast for readability.
- Ensure all cards are aligned and equal height.
- Ensure sticky header does not consume too much mobile screen space.
- Ensure floating WhatsApp/chat button does not overlap mobile sticky CTA.
- Keep forms short and easy to complete.
- Use clear success and error states for all forms.

- Reduce unused JavaScript

- Keep enquiry and campus visit forms lightweight
- Minify CSS and JavaScript
- Use caching and CDN
- Improve Core Web Vitals, especially LCP and FCP
- Avoid heavy animation libraries
- Optimize fonts and avoid unnecessary font weights
