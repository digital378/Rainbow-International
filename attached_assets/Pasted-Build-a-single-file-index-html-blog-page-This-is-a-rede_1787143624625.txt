Scroll-Storytelling Animation System

This is the heart of the page. Implement a scroll-driven character animation system using requestAnimationFrame + a scroll event listener.

Walking animation: Each character has 3 walking frames. Use JavaScript to swap the src of a single <img> element at 8fps to create the walk cycle. Keep a setInterval running at 125ms that cycles through frames 1→2→3→1 only while the character is actively "walking" (i.e. visible and scroll is moving).

Scroll-driven horizontal movement: As the user scrolls past each section, characters move horizontally using transform: translateX() tied to scroll progress. Boy enters from the left, girl from the right. When they "meet," swap to the appropriate pair image.
