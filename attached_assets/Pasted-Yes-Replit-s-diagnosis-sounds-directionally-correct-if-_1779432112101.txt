My recommendation

First test with a minimal OpenAPI schema containing only debugHeaders. If that works, the issue is likely schema size/structure/one bad endpoint definition. If even that fails, the issue is almost certainly the GPT Action configuration, privacy/domain trust, or ChatGPT-side connector state.

Also make sure the GPT is using a supported model for Custom Actions. OpenAI’s release notes mention that GPTs with Custom Actions support specific models, including GPT-4o and 4.1, so model/action compatibility should also be checked in the GPT editor.
